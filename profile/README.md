# Statia

Statia is an AI-powered platform for accessing, exploring, and analyzing
official statistical data from the Agence Nationale de la Statistique et de
la Démographie (ANSD).

The project aims to make statistical information easier to discover,
understand, and use through natural language and modern data tools.

## About

Statia is developed as part of the ANSD innovation initiative and focuses on
making official statistical data more accessible to researchers, journalists,
entrepreneurs, public decision-makers, and other users.

## Repositories

This organization contains the source code and documentation of the Statia
project.
